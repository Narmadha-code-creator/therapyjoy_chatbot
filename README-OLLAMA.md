# TherapyJoy - Ollama AI Chatbot (ZERO API KEYS!)

## 🚀 LIVE - Local Only

**Status:** ✅ **Ollama ready** (no cloud keys!)

## Quick Start (5 mins)

**1. Install Ollama:**
```
https://ollama.com/download → Windows
```

**2. Terminal 1:**
```
ollama serve
```

**3. Terminal 2:**
```
ollama pull llama3.2
```

**4. Run Chatbot:**
```
npm start
```

**5. OPEN:**
```
http://localhost:5000/
```

## Features
- ✅ Local AI (llama3.2)
- ✅ Emergency detection
- ✅ Chat history 
- ✅ Modern UI
- ✅ No API costs/keys
